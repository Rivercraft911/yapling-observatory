# IGRF-14 Earth-fixed field

`igrf14.field_ecef_t(position_ecef_m, decimal_year, max_degree=13)` returns a 3-tuple of tesla in the same geocentric Earth-fixed Cartesian axes as the input metres: X at the equator and Greenwich meridian, Y at 90° east, Z north. `field_ecef_t_at_utc(position, epoch_utc, elapsed_s=0)` accepts an explicit ISO UTC epoch and elapsed SI seconds. `utc_decimal_year` accounts for leap days and calendar-year rollover. Epoch text has microsecond precision. The caller supplies geodetic, orbit-frame, time-scale and spacecraft-body transformations.

The supported time interval is 2025.0 through 2030.0, including both endpoints. Geocentric radius must exceed 3485 km, following the official reference program's core-mantle-boundary guard; kilometre-valued Cartesian inputs are rejected. This is an internal main-field model, without external disturbances, spacecraft magnetic fields or magnetometer behavior. It establishes no sensor or controller performance. Degrees 1 through 13 are selectable for validation and truncation studies; the legacy mission degree-one implementation remains separate and unchanged.

The scalar potential and its negative gradient follow Beggan et al. (2026), section 2, [doi:10.1186/s40623-025-02360-0](https://doi.org/10.1186/s40623-025-02360-0). Schmidt semi-normalization has no Condon–Shortley phase; the reference radius is 6371.2 km. Main-field harmonics extend through degree 13. Predictive 2025–2030 secular variation extends through degree 8; degrees 9 through 13 remain fixed. Associated Legendre functions, their colatitude derivatives and the ratio P/sin(theta) are propagated by recurrence. The implementation never divides by sin(theta), including exact poles. Coefficient and UTC-epoch caches each retain at most 4 entries. Dates are not quantized. No runtime network or external scientific library is required.

## Coefficient source and terms

`igrf14coeffs.txt` is the unmodified official [NOAA/NCEI coefficient file](https://www.ngdc.noaa.gov/IAGA/vmod/coeffs/igrf14coeffs.txt), retrieved 25 October 2026 PDT (26 October UTC). SHA-256: `8f8d88403028fc4ee92c4f38d97b46e0a87e2cfc496045b43c9e26c1d6b0903c`. Its MD5, `3606931c15c9234d9ba8e2e91b729cb0`, matches the corresponding file in the primary [IAGA Zenodo v2 release, 25 November 2024](https://doi.org/10.5281/zenodo.14218973). It contains 195 main-field coefficients per modern epoch; this module reads only 2025 and the 2025–2030 SV column. The checked byte hash, row structure, complete degree/order set and absent high-degree SV are validated on import.

## Verification

Independent official synthesis reference vectors accompany the module. Additional tests cover the degree-one Cartesian dipole, exact and near-pole continuity, secular variation, date and SI input bounds, and bounded caches. Numerical agreement verifies implementation rather than the model's instantaneous physical uncertainty. Timing records are kept with the numerical verification work; a per-field-call benchmark is distinct from whole-mission runtime.
