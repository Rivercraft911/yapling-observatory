The global day map is the unmodified original 8192x4096 JPEG from the publisher. GPUs supporting less than 8192px use its preserved 4096x2048 fallback. The earlier Solar System Scope global cloud JPEG and grayscale PNG are retained as legacy assets; runtime cloud LOD now uses the matched NASA maps below. Legacy fallback changes were Lanczos downsampling and grayscale PNG cloud conversion. Ocean/specular mask converted from TIFF to grayscale PNG. Rendering adjusts saturation, lighting, cloud opacity and material response. Geography was not generated or redrawn. See asset-provenance.json for exact sources, sizes and SHA256 hashes.

Rendering: a display-only approximate atmosphere and Sun direction, independent of RF, weather, orbital dynamics and delivered data. The orbit arc is only the returned synthetic Run history. Locator sizes are exaggerated.

Native cloud tiles for close cameras

NASA Goddard Space Flight Center / Reto Stöckli (clouds); Robert Simmon (compositing enhancements)
https://science.nasa.gov/earth/earth-observatory/the-blue-marble-true-color-global-imagery-at-1km-resolution/
https://www.nasa.gov/nasa-brand-center/images-and-media/

The original western and eastern 21600 × 21600 grayscale PNGs form a 43200 × 21600 global grid, with native angular spacing 1/120 degree and a published nominal1km product class. The242 runtime WebP derivatives preserve that native sampling; each interior is at most2032 × 2032 pixels, with eight real neighboring-pixel gutters. Longitude gutters wrap and pole gutters clamp to original edge pixels. WebP quality90/method4 introduces documented lossy compression. There is no resizing, sharpening, inpainting or procedural cloud detail. The source2001 multiday composite, known mosaic boundaries and data limitations are retained. These clouds do not describe the simulated date or measured RF/thermal conditions, and are coarser than the500m regional daytime map.

The curated tile set totals86,643,482bytes. The renderer selects up to nine local tiles from the actual close-camera position, with at most two loads in progress and per-tile size/SHA/dimension checks. Single-channel R8 textures limit cloud tile GPU storage to48MiB including mipmaps, plus at most36MiB retained CPU mask data. Two temporary bitmap/canvas decodes add transient memory. Tiles are released on eviction, after15s outside the needed view, and immediately on view disposal. The matched NASA global 8K/4K map remains outside loaded coverage, near some horizon/polar edges, on failure and in far views. Adjacent tiles use native gutters; exposed coverage edges and camera distance feather to area-reduced coverage from the same NASA composite. Visible cloud opacity and approximate surface shadows share the same sampler, coordinates and tile weights. No runtime external requests occur.

See /earth/cloud-tiles.json for every tile identity, native pixel bounds, complete source hashes, acquisition limits, measured compression errors and licensing. This display-only layer is independent of numerical weather, RF, power and thermal models. No NASA endorsement is implied.

Matched global NASA cloud coverage

The global earth-clouds-nasa-8k.webp (8192 x 4096) and earth-clouds-nasa-4k.webp (4096 x 2048) maps use the exact same checked NASA 2001 western and eastern source images as the native cloud tiles. Each native grayscale hemisphere is area-reduced with Pillow BOX resampling to 4096 x 4096; the halves join west then east. The 4K map is an additional 2 x 2 BOX reduction of the 8K map. Lossless WebP encoding preserves every reduced coverage value exactly, with equal red, green and blue channels. No sharpening, gap filling, altered polar coverage or procedural detail is added. Native blank areas and mosaic artifacts remain. These maps retain the NASA credits, imagery-use terms and observation limits given above.

The original western and eastern NASA images contain a hard cloud-coverage join at longitude 0 degrees over the Southern Ocean. That fixed geographical seam remains in both the global maps and native tiles. It exists in the checked source pixels before resampling or rendering and is separate from the corrected camera-dependent switch between cloud composites. No source pixels were painted in to conceal it.

Using a single source composite avoids switching between different cloud coverage when camera LOD changes. The current TextureLoader stores these global maps as RGBA8 and samples red with NoColorSpace; GPU storage with mipmaps is about 170.67 MiB for 8K or 42.67 MiB for 4K, the same format budget as the previous global maps. Native tiles retain their separately recorded R8 storage. Lossless global encoding and lossy native-tile encoding can differ at individual pixels, and downsampling removes high-frequency detail. Source dates do not describe simulated-time weather. See /earth/cloud-global.json for complete source and runtime SHA-256 identities, transformations, dimensions and round-trip checks.

Night lights

Solar System Scope / INOVE
https://www.solarsystemscope.com/textures/
https://creativecommons.org/licenses/by/4.0/

The night-light maps are the unmodified 8192x4096 and 2048x1024 publisher JPEGs, distributed under CC BY 4.0. The 2K original is used when the GPU does not support the 8K texture. Runtime appearance uses a restrained emissive gain and a smooth daylight fade; cloud opacity can obscure the lights. The publisher supplies adjusted composite imagery without a single observation epoch. These maps are not current city activity, simulated-date observations, calibrated light radiance, weather or spacecraft thermal inputs. No buildings, city geometry or procedural light locations are generated. Source URLs, sizes and SHA-256 identities are recorded in asset-provenance.json.

Credit: NASA Earth Observatory, Black Marble 2016 / Suomi NPP VIIRS.

The original 13500 x 6750 grayscale JPEG is bundled unchanged. Its native grid covers the full globe at 0.026666667 degrees per pixel; NASA describes the product as 3 km. Runtime R8 storage keeps the complete mip chain to about 115.87 MiB on compatible GPUs, less than the previous 8K RGBA map. A power-0.65 display curve brings out faint existing lights while preserving black and peak values; a warm tint and the existing 0.35 emission gain remain visual choices. This annual composite is not the simulated date, calibrated radiance, weather, RF attenuation or a thermal input. Smaller GPUs and failed loads retain the earlier 8K/2K maps and their credits above. See night-map.json for source hashes and runtime memory bounds.
